# @aibizhive/dsh-web-app-aibizhive-full

Full AIBizhive bundle for DSH web profile.

What it does:
- Serves `/brand/aibizhive-icon.png` (real file)
- Overrides `/manifest.webmanifest` to AIBizhive name/short_name/icon
- Provides AIBizhive client UI overrides (theme/brand/conversation) and title enforcement

Install by adding this package to your web profile bundles.
